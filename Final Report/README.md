# Data Quality Assessment – Report

This folder contains the final report for the SQL-based Data Quality Assessment of the Olist Brazilian E-Commerce dataset.

## Contents

- **Final Data Quality Assessment Report:** Detailed documentation of the assessment process, key findings, identified data quality issues, and recommendations.

## Purpose

The report summarizes the results of data quality checks performed using MySQL, highlighting data inconsistencies, validation outcomes, anomalies, and improvement recommendations.

## Tools Used

- MySQL Workbench
- Microsoft Excel
- Microsoft Word

This report presents the overall findings and conclusions of the project.
