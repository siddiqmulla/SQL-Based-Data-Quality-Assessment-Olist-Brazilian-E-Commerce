# SQL Data Quality Assessment

This folder contains SQL queries developed to perform data quality assessment on the Olist Brazilian E-Commerce dataset using MySQL.

## Assessment Activities
- Record count validation
- Data completeness checks
- Duplicate detection
- Referential integrity validation
- Data type and format checks
- Payment and order validation
- Date and timestamp consistency checks
- Anomaly detection

## Tools Used
- MySQL
- MySQL Workbench

## File
- `SQL_Queries.sql` – SQL scripts for data quality assessment.

These queries help identify data inconsistencies, missing values, and potential quality issues in the dataset.
