# Data Quality Assessment – Outputs

This folder contains the output files and screenshots generated during the SQL-based Data Quality Assessment of the Olist Brazilian E-Commerce dataset.

## Contents

- **Output Files:** Excel files containing SQL query results, validation summaries, and data quality findings.
- **Screenshots:** Screenshots of SQL queries and their execution results from MySQL Workbench.

## Purpose

These outputs provide evidence of the data quality assessment performed on the dataset, including completeness checks, duplicate detection, referential integrity validation, and anomaly identification.

## Tools Used

- MySQL Workbench
- Microsoft Excel

The files support the findings and recommendations presented in the final Data Quality Assessment Report.
