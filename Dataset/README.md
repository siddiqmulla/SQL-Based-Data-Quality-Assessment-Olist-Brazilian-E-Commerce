# Dataset – Olist Brazilian E-Commerce

This project uses the **Brazilian E-Commerce Public Dataset by Olist**, available on Kaggle.

The dataset contains Brazilian e-commerce transaction data, including customer information, order details, payment records, and order statuses. It is used to perform SQL-based data quality assessment.

## Dataset Source

**Kaggle:** [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Tables Used
- `customers`
- `orders`
- `order_payments`

## Purpose

The dataset is used to identify missing values, duplicates, inconsistencies, referential integrity issues, and other data quality problems using MySQL.

## Data Source

The dataset is publicly available on Kaggle and is provided by Olist for educational and analytical purposes.
